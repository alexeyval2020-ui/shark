# shark.ru

Статический сайт: открывается двойным кликом по index.html или выкладывается на любой хостинг.

## Как выложить
1. Cloudflare Pages / Netlify / GitHub Pages: загрузите содержимое папки (index.html должен лежать в корне).
2. Обычный хостинг: загрузите все файлы в папку public_html.
3. Домен: у регистратора направьте shark.ru на выбранный хостинг (A/CNAME-записи покажет сам хостинг).

## Как обновлять матчи
Откройте data/matches.js и допишите строки вида:
['rpl','2026-11-15T16:00','Зенит','Спартак']
Время по Москве. Лиги описаны в блоке leagues в том же файле.

## Что внутри
- index.html: разметка и метатеги
- style.css: оформление
- app.js: логика (даты, фильтры, избранное, прогнозы в браузере)
- data/matches.js: расписание
- assets/: аватарка и значки
